## Task 1: Balance the message ref on the invalid-channel send path (🟡 Medium)

**Problem:** `pomelo_session_send` calls `pomelo_message_prepare_send` (which refs the message +1 and sets the BUSY flag) at the top. The `signature == 0` branch correctly calls `pomelo_socket_dispatch_send_result` before returning (that function runs `finish_send` to drop the ref and clear BUSY, and invokes the send callback). But the `if (!channel) return;` branch just returns — so on an invalid `channel_index` the message's ref is leaked (never returned to the pool), its BUSY flag is stuck (unusable forever), and the send callback is never invoked (the caller may wait indefinitely).

**Files:**
- Modify: `src/api/session.c` (`pomelo_session_send`, ~lines 41-67)

- [ ] **Step 1: Read `src/api/session.c`.** Confirm `pomelo_session_send` reads:

```c
void pomelo_session_send(
    pomelo_session_t * session,
    size_t channel_index,
    pomelo_message_t * message,
    void * data
) {
    assert(session != NULL);
    assert(message != NULL);

    // Prepare the message for sending
    pomelo_message_prepare_send(message, data);

    uint64_t signature = pomelo_session_get_signature(session);
    if (signature == 0) {
        pomelo_socket_dispatch_send_result(session->socket, message);
        return; // Session has been released
    }

    // Get the channel
    pomelo_channel_t * channel =
        pomelo_session_get_channel(session, channel_index);
    if (!channel) return; // Invalid channel

    // And send through it
    assert(channel->methods != NULL && channel->methods->send != NULL);
    channel->methods->send(channel, message);
}
```

- [ ] **Step 2: Dispatch the send result on the invalid-channel path**

Change the `if (!channel)` branch so it finishes the send (balancing the ref, clearing BUSY, and firing the callback with the default `nsent = 0` failure result), exactly like the `signature == 0` branch:

```c
    // Get the channel
    pomelo_channel_t * channel =
        pomelo_session_get_channel(session, channel_index);
    if (!channel) {
        // Invalid channel: finish the send so the message ref/BUSY flag are
        // balanced and the send callback is still invoked (as a failure).
        pomelo_socket_dispatch_send_result(session->socket, message);
        return;
    }
```
